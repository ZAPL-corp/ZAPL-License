How to Activate ZPL

  1. Go to the repository where you want to activate the license.
  2. Create or edit the existing LICENSE file and paste the snippet below:
Project working in ZAPL LICENSE! LICENSE - https://github.com/ZAPL-corp/ZAPL-License/blob/main/LICENSE Corporation - https://github.com/ZAPL-corp/ Information About Working License (IAWL) - https://github.com/ZAPL-corp/ZAPL-License
Done! Your project now fully supports the ZAPL License.
